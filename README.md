# Student Performance Exploratory Data Analysis (EDA)

## Project Overview
This project explores a cleaned student dataset using Python to understand data patterns, summarize statistics, and identify potential relationships between numerical variables.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Project Tasks
- Loaded and explored the cleaned dataset
- Checked missing values and duplicate records
- Generated descriptive statistical summaries
- Created visualizations to explore data distributions and relationships
- Calculated correlations between numerical columns
- Saved EDA summary and correlation results as CSV files

## Visualizations
- GPA distribution
- Student count by grade class
- Weekly study time vs GPA
- Absences vs GPA
- Tutoring status vs GPA

## Files
- `Student Performance EDA - Task 2.ipynb` — EDA notebook
- `eda_summary.csv` — Statistical summary
- `correlation_matrix.csv` — Correlation results

## Key Learning
Practiced data exploration, statistical analysis, data visualization, and interpreting patterns using Python.
